# Realizar un caso de estudio para el proyecto.

Investigar, preguntar o extraer información de documentos de forma
general o especifica que detalle los problemas típicos que los usuarios
tienen cuando se comunican con el equipo de soporte de una aplicación.

**Nota:** *Pueden buscar datasets (archivos de Excel, CSV, Bases de
datos) relacionados a \"Mensajes de usuario en aplicaciones de
mensajerías\" o \"Mensajes de usuario para soporte técnico\".*

### Ejemplo del proyecto \"Conversacional IA\"

Problemas que el usuario tiene cuando envía un mensaje al equipo de
soporte de \"Conversacional IA\"

1.  Los usuarios se frustran (*ej. No resolvieron su duda, no obtuvo
    respuesta, etc.*)

2.  No se logra identificar el tono emocional ni la intención del
    mensaje del usuario (*ej. quiere ayuda, tiene un problema con la
    aplicación, necesita más información del servicio o producto, etc.*)

3.  El usuario no entiende el servicio o producto y lo abandona.

Lo que ya hace la aplicación \"Conversacional IA\"

- Contabiliza el porcentaje de mensaje resueltos (no se sabe con que
  criterio se contabiliza)
